General support & reporting issues

The fastest way to get support for any of our mods is through our GitHub Issues pages. Please check if your issue has already been reported before opening a new one.

Scripta Issues Florarium Issues

If you found a bug, please include your mod version, Minecraft version, loader version, and a latest.log file in your report. For content problems (a quest that will not load, a recipe that will not fire), include the relevant JSON file and any Quest parse error or datapack lines from the server log.

Scripta FAQ

The mod loaded but there are no quests

That is expected. Scripta ships three starter categories but zero quests. Quests are yours to author. Start in the quest reference or use an editor.

Do I need to install OwoLib?

No. OwoLib is bundled inside the Scripta jar. Installing a separate OwoLib jar will trigger a duplicate-mod error.

My quest does not appear

Check that its category points at a category ID that exists, its ID is unique, and you ran /reload after manual edits. Check the server log for parse errors.

Where do I get the web editor link?

Operators receive it automatically in chat on join. You can also run /scripta web (operator level 2) to send it again.

How do I reset a player?

Run /scripta reset <player> as an operator. Note that this resets progress but keeps the record of claimed rewards for data integrity.

The full FAQ — authoring, rewards, the web editor token, loot crates, progress resets, and log reading — lives at Scripta FAQ.

Scripta troubleshooting

The mod will not load

  • Confirm Minecraft is exactly 1.21.1.
  • Confirm Fabric Loader is 0.16.9 or newer.
  • Confirm Fabric API and Architectury API are both installed.
  • Remove any separate OwoLib jar — it is already bundled.

A quest shows up as Unknown reward

The quest uses a reward type this version does not know. Scripta keeps it intact rather than discarding the quest, so it will start working once the server runs a version that supports that type.

My theme change did nothing

  • Check the surface name for typos — unrecognised values fall back to PANEL silently.
  • Check colours are valid 32-bit values if you hand-edited the file.
  • Confirm you saved — an unsaved theme is never broadcast.

Reading the server log

Scripta prefixes its messages, so filter for [scripta] — loaded quest/category counts, quest parse errors, skipped rewards, and web editor port problems all show up there. Full detail: FAQ troubleshooting.

Florarium status

When can I download Florarium?

Florarium is currently in active development and is not yet available for public download. There is no release date — follow the Florarium docs to see what is built and what is still roadmap.

Which Minecraft version will it support?

Like all current Sparda projects, Florarium targets Minecraft 1.21.1 on Fabric (Java 21, Mojang mappings), with Fabric API, Spell Engine, Spell Power, and Tiny Config as dependencies.

Can I report issues or contribute before release?

Yes — the Florarium issue tracker is open. Design questions are welcome too; reference the bloom chain or Bloom Magic status pages so we know which system you mean.

Divinity Music status

When can I download Divinity Music?

Divinity Music is in development and is not yet available for public download. The seven discs are built; divine artifacts, acquisition tuning, and release packaging are still roadmap. See the Divinity docs.

Which Minecraft version will it support?

Minecraft 1.21.1 on Fabric (Java 21), with Fabric API as its dependency.
