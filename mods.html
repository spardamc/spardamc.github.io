Scripta

Available now v1.0.0 Fabric 1.21.1
Download on CurseForge

Sparda's released mod: a data-driven global questing mod for Minecraft 1.21.1 on Fabric. Quests are authored once as JSON data, loaded like advancements, and identical across every world and server — players only carry progress state.

  • Five objective types — break blocks, kill entities, collect items, reach custom stats, grant advancements — each with its own required count.
  • Eleven reward types — items, XP, XP levels, commands, advancements, toasts, weighted tables, loot crates, and interactive player choices.
  • Weighted reward tables — roll one prize, grant them all, or hand over a physical loot crate the player opens themselves.
  • Two editors — a browser-based web editor with a tokenised operator link, plus a full in-game editor behind operator level 2.
  • Per-player progress — completion, objective counters, and claimed rewards persist per player in world SavedData and sync on join.
  • Themeable quest book — per-pane surfaces, colours, sizes, and widget styles, including custom background textures.

Requires Minecraft 1.21.1, Fabric Loader 0.16.9+, Fabric API, and Architectury API. OwoLib ships inside the Scripta jar — do not install it separately.
