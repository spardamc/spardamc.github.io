Installation

Scripta 1.0.0 targets Minecraft 1.21.1 on Fabric. Install it on the client, the server, or both.

  2. Installing with CurseForge / Prism

Requirements

ComponentVersionNotes
Minecraft 1.21.1 Scripta does not load on other versions.
Fabric Loader >= 0.16.9 Required.
Fabric API any Required, install separately.
Architectury API any Required, install separately.
OwoLib — Bundled inside the Scripta jar. Nothing to install.
OwoLib is already inside The release jar declares OwoLib as a nested jar. If you also drop a separate OwoLib jar into mods/ you will get a duplicate-mod error — pick one or the other.

Installing with CurseForge / Prism

  1. Open the Scripta page on CurseForge.
  2. Choose the 1.21.1 file: scripta-fabric-1.21.1-1.0.0.jar.
  3. Create or edit a Fabric 1.21.1 profile and add Scripta to it.
  4. Add Fabric API and Architectury API to the same profile.
  5. Launch.

Manual installation

  1. Install Fabric Loader for Minecraft 1.21.1 if you have not already.
  2. Download scripta-fabric-1.21.1-1.0.0.jar from CurseForge.
  3. Copy it into your instance's mods folder, alongside your fabric-api and architectury-api jars.
  4. Launch Minecraft using the Fabric profile.

The mods folder is usually at:

Windows %appdata%\.minecraft\mods macOS ~/Library/Application Support/minecraft/mods Linux ~/.minecraft/mods Modrinth / Prism instances: <launcher>/instances/<profile>/.minecraft/mods

Dedicated server setup

Put the same three jars in your server's mods folder — Scripta, Fabric API and Architectury API — then start the server.

Players need it too Scripta renders a client-side quest book. Anyone joining your server must install the client jar too, or they will see no quest book.

Scripta is present on both sides:

  • Server owns quest definitions and player progress, and hosts the web editor.
  • Client receives definitions and progress on join, and renders the quest book GUI.

Changing the web editor port

The web editor listens on port 25566 by default. Override it with a JVM system property on the server: 

java -Dscripta.webport=8080 -Xmx4G -jar server.jar nogui
Expose it carefully The editor binds on all interfaces. Anyone who has the token can edit your quests, so do not port-forward it to the open internet without a reverse proxy or firewall rule.

Verifying the install

In game, run:

/scripta list

You should see the three categories that ship with the mod, each with no quests yet:

== Getting Started == == Combat Basics == == Exploration ==
No quests yet is expected Scripta ships three starter categories but no quests. Quests are yours to author — see Quests & categories.

Then press G or run /quests to open the quest book.
