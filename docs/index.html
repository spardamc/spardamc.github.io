Scripta

A data-driven global questing mod for Minecraft 1.21.1. Author quests as JSON, hand them out as items, XP, commands, advancements, weighted loot tables or interactive choices — and let players work through them in an in-game quest book.

What Scripta does

Global, data-driven quests

Quests and categories live as JSON in your datapack, so they are identical on every world and server — only player progress is per-world.

Quest reference →

Five objective types

Break blocks, kill entities, collect items, reach custom stats and grant advancements — each with its own required count.

Eleven reward types

Items, XP, XP levels, commands, advancements, toasts, weighted tables, loot crates and interactive player choices.

Weighted reward tables

Roll one prize, grant them all, or hand out a physical loot crate item the player opens themselves.

Browser web editor

Operators get a tokenised link on join. Edit quests, categories, tables, presets, icons and theme from a browser — live.

In-game editor

A full quest editor built into the game, behind operator level 2, for when you would rather not leave Minecraft.

Per-player progress

Five minute setup

  1. Install Scripta 1.0.0 plus Fabric API and Architectury API. OwoLib ships inside the Scripta jar. See Installation.
  2. Start a world and run /scripta list to confirm the three starter categories loaded.
  3. Op yourself, then run /scripta web and click the link in chat to open the editor. (Or use /questedit in-game.)
  4. Put a quest in the Getting Started category, add an objective and a reward, and press Save.
  5. Press G (or run /quests) to open the quest book and see your quest appear instantly.
Progress is per player, content is global Quests are read from datapacks and shared by everyone. Deleting a quest JSON prunes it from every player's completed list on the next tick.

Who is it for?

  • Server operators who want a quest book without hand-writing an entire quest engine.
  • Pack authors who prefer plain JSON over an in-world node graph.
  • Players on a server that already runs Scripta — the client jar is all you need.
