Commands & keybinds

Everything Scripta adds to your command list and keybind settings, in one place. Operator level 2 is required for anything that changes quests.

/scripta — server commands

CommandWhoWhat it does
/scripta list Anyone Prints every category and quest, sorted by category order then quest title. Completed quests are marked [x], the rest [ ]. Prints No quests loaded. if nothing is loaded.
/scripta sync Anyone Re-sends your quest progress and the quest definitions to you. Use it if your quest book looks out of date.
/scripta web Op level 2 Sends the clickable web-editor link in chat. Says The web editor is not running. if the port could not be bound.
/scripta reset <player> Op level 2 Clears another player's quest progress and re-syncs them. The player must be online.
/scripta reset Op level 2 Clears your own quest progress.
/scripta reset does not clear claim records Reset clears completed quests and objective counters, but the record of which rewards were already claimed is kept. If you reset a player and they had already claimed a manual-claim reward, that reward will still read as claimed. Edit scripta_progress.dat directly if you need a truly clean slate.

Client commands

These run on your client only — they never reach the server.

CommandWhat it does
/quests Opens the quest book.
/questedit Opens the full in-game editor. Opens for anyone, but the server rejects every edit from non-operators with You need operator level 2 to edit quests.

Keybinds

ActionDefaultTranslation key
Open the quest book G key.scripta.quests — shown as Open Quests

Rebind it under Options → Controls in the Scripta category. The keybind only fires while no screen is open.

Permissions & enforcement

  • list and sync need no permission level.
  • web and both forms of reset require operator level 2.
  • Every edit from the in-game or web editor is re-checked server-side on receipt. Client-side checks are cosmetic — a modified client cannot save quests without op.
  • Operators receive the web-editor link automatically in chat when they join while the server is running.

Reloading

There is no /scripta reload. Quest and category JSON is read through the normal datapack reload system, so use vanilla: 

/reload

Edits made in either editor apply immediately without a reload — they are broadcast to every connected player within a second. Quests you deleted in an editor stay deleted even after /reload.
