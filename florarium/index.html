Florarium

A magic-tech mod built around a mana economy and a flower-based progression chain. The core loop: generate mana with flowers → spend it at crafting stations → craft the next flower in the chain → unlock deeper tiers. It also includes tiered ore-generating machines (Bonsai Miners), a custom particle FX system, and a spell-casting bridge to the Spell Engine mod.

How it plays

The flower chain is the tech tree: each flower crafts the next via the Bloom Apothecary. If you are ever lost, the in-game Divinity Guide book lists station recipes and builds.

  1. Stage 0 — First pool and first spark: craft a Mana Pool, plant an Ember Wick, Apothecary-craft a Petal Rain.
  2. Stage 1 — Apothecary chain: work through Kindle Bloom and Harvest Bloom, then craft the Wand of Binding and the Architect Wand.
  3. Stage 2 — Ring rites: raise the Apothecary ring (an Apothecary plus 4 Bloom Pedestals) and craft Frostbloom through Rune Bloom.
  4. Stage 3 — Forge tier: craft Cinder Bloom through Bloomheart Core, ending at Genesis Bloom and the Prism Bloom capstone.
  5. Stage 4 — Awakened blooms: use the late flowers' abilities — village reveal, cloning, mass crop growth, and more.

Alongside the chain run the side systems: utility flowers, condensed 2.5× variants, automation via hoppers and Mana Relays, and Prism Ore mining deep underground. See the bloom chain page for the full walkthrough.

Still being built

The following are known work-in-progress areas, not finished features:

  • Bloom Magic 2.0 engine — API interfaces, wand management, and the legacy mana bridge exist; spell catalog loading, wand UI, and full runtime integration are ongoing.
  • Bonsai Farmer — stub block only.
  • Glowing Ore — stub block only.
  • GeckoLib — dependency disabled; wand and projectile animations are not yet wired.
  • JEI — compile-only API for now; full recipe integration is pending.
