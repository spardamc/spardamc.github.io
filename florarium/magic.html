Bloom Magic 2.0 engine

Work in progress The engine structure is in place with API interfaces, wand management, and the legacy mana bridge. Full 2.0 integration — spell catalog loading, wand UI, and the complete runtime — is still being built.

A modular spell-casting engine kept deliberately decoupled: it owns the rules, Florarium owns the content. Its parts:

  • MagicPlatform — injection point; the engine never touches mod-specific code directly.
  • ManaAccess / EssenceAccess — interfaces for mana and essence backends.
  • WandAccess — wand NBT read/write, socket management, tier upgrades.
  • SpellCatalog — datapack-driven spell definitions (bloom_magic/spells/).
  • SpellRuntime — per-server cast execution, cooldowns, delayed effects.
  • BloomMagicEngine — front door: bootstrap, commands, server tick, player join/leave/death hooks.

FX system

A custom particle framework where every effect is described the same way — five settings, whatever the particles are made of:

SettingMeaningRange
paceSpeed multiplier (also shortens/lengthens lifetime)0.05–10
opacityTransparency; 0 = invisible, 1 = solid0–1
sizeParticle diameter in blocks0.01–8
shapeEmission geometry particles spawn in and travel along9 patterns
colorRGB tint0xRRGGBB
  • 3 sprite shapes — SOFT_CIRCLE, STAR, SQUARE.
  • 9 emission patterns — POINT, SPHERE, BALL, RING, DISC, CUBE, LINE, HELIX, CONE.
  • 15+ presets — e.g. MAGIC_RING, ARCANE_SPIRAL, EMBER_BURST, HEAL_SPARKLES, END_ROD_SPIRAL.
  • StationFx — living-state VFX for machines (working, charging, starved, blocked, ready).
  • BreakEffects — every flower and station bursts into themed particles when broken.
  • ArcEffects — bezier path effects for mana transfer visualisation.
  • FxTuning — global budget gate; respects reduced_motion / reduced_flash config.

The house dialect: star wisps for transfers, rings for rituals, ember bursts for fire, teal mana glow for pool events. Breaking any flower or station pops its themed burst.

Configuration

config/divinity_additions.json is JSON-backed and auto-created on first run, with hot-reload support. It covers miner tiers, farmer tiers, chunk loader radii, glowing ores (enabled, light level), and FX (reduced_motion, reduced_flash, sound_volume).
