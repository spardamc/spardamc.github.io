Credits & Attributions

Our work is built on the shoulders of giants in the Minecraft modding community:

  • Fabric API — the foundation of everything we do; required by all three projects.
  • Architectury API — the multi-loader framework behind Scripta's shared common module.
  • OwoLib — the UI framework driving Scripta's quest book and editors; bundled inside the Scripta jar.
  • Spell Engine + Spell Power — the spell framework Florarium's mana bridge hooks into.
  • Tiny Config — backs Florarium's JSON configuration with hot-reload support.
  • JEI and GeckoLib — Florarium integrates against them (JEI compile-only for now; GeckoLib currently disabled pending animation wiring).

All current projects target Minecraft 1.21.1 on Fabric with Java 21; Florarium is written against Mojang mappings.

Want to contribute? We are always open to feedback and bug reports. Check our GitHub repositories to see how you can help.
